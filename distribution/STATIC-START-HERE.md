# Mii Editor — static web-hosting edition

Upload this folder's contents to an ordinary static website. `index.html` and `assets/` work at the domain root or a directory such as `/mii-editor/`. Keep the legal notices. See HOSTING.md for Apache examples; Nginx or other static hosting only needs normal index-file and MIME handling.

No startup script, Python, Node.js, Vite, PHP, Go, database or runtime application backend is needed on the hosting server. This is not the double-click local edition; download your platform's local ZIP for that. Do not open index.html through file:// because browser module restrictions can prevent it working.

Shared URLs use the current hosted origin/path. HTTPS is recommended on a public site. Browser storage belongs to the origin; export important Miis before changing domains, protocol or port.
