# Start Mii Editor Web

1. Extract this entire folder. Do not open index.html directly.
2. For local use, install Python 3 (3.9+) if needed: https://www.python.org/downloads/. It is not bundled.
3. Windows: double-click start-windows.bat. macOS: open start-macos.command, or run `bash start-macos.command` in Terminal. Linux: run `bash start-linux.sh`.
4. Your browser opens http://127.0.0.1:8765/. Keep the terminal open. Press Ctrl+C to stop.

To self-host, upload only the contents of website/ to your static server. No Python, Node.js, Vite, Flash, PHP, database or cloud service is needed on an Apache production server. See HOSTING.md for root and /mii-editor/ examples, updates and browser limitations.

Use File to load/save .mii or XML and export PNG/JPEG. Important characters should also be saved as files; browser storage can be cleared. Share links contain complete character data. This is a preview, not full mobile/cross-browser or physical Wii certification.
