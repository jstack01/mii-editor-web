# Historical default characters

The named Default Boy and Default Girl anchors at https://mii-editor.nekoweb.org/ were retrieved for Milestone 6.2. Their exact 74-byte records are pinned in web/src/model/characterPresets.ts. The boy record exactly matches the already recovered ClassicGUI.as default. The girl record comes from the reference page (not an invented gender/style combination); its name is defaultGrl, as shown in the supplied screenshot. Both source records pass the existing software profile. No source HTML, Flash packages or decompiled code is added to the public tree.

Reference page SHA-256: 8ce13d3fdd09387f3169d8cbff7e04ebda41bcb70c32aeaf82828cd54630bbaa. The original records retain historical IDs/owner data as test/provenance inputs. Each explicit link load keeps every other byte unchanged but allocates a fresh normal persistent ID through the existing high-water allocator and leaves console ownership unknown (zero). No destination identity is invented. Appearance, numeric attributes, names, palettes and reserved bits stay unchanged. Tests compare all nonidentity bytes and rendered feature geometry; screenshots document the current renderer, not independent pixel-perfect or hardware certification.

Links replace the current character immediately like existing explicit loads, using the same commit/persistence/share update path. They do not alter startup precedence or reset on refresh. Open modals remain modal; repeated loads allocate different IDs. There are no runtime requests to the reference website. Historical graphics rights and software/hardware limitations remain in NOTICES.md and web/WII_PROFILE.md.
