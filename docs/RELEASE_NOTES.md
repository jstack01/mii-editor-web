## Mii Editor Web v0.1.0-preview.4 — prerelease

D3 adds a small, non-root Nginx Docker image and ready-to-use Compose distribution for the same static editor. Container image: **ghcr.io/jstack01/mii-editor-web:v0.1.0-preview.4**, with linux/amd64 and linux/arm64 under one multi-platform tag. Public package status and anonymous pulling must pass verification before this prerelease is published. No Docker Hub publication occurs.

The image needs no Node.js, Python, Vite, PHP or database at runtime. Compose publishes only 127.0.0.1:8080 by default and includes read-only root storage, ephemeral /tmp, dropped capabilities and no-new-privileges. Change MII_EDITOR_PORT in .env for a different host port; launcher config.json is not used by Docker. Miis remain in browser storage/downloads. Export important .mii files before changing hostname or port. Public hosting should use a deliberately configured HTTPS reverse proxy.

Download a Windows/macOS/Linux launcher ZIP, the ordinary static-hosting ZIP, or the Docker starter ZIP containing compose.yaml, .env.example, START-HERE and notices. Checksums cover all five. The starter pulls the published GHCR image; it does not bundle a compiled launcher or image tarball. GitHub Source code archives still require a developer build. Earlier preview.1/2/3 releases stay unchanged.

Local Docker Desktop testing on macOS ARM64 built both platforms, ran ARM64 natively in its Linux VM and AMD64 under emulation, and exercised the actual Compose service. Tests cover all 13 screens, original vectors, presets, randomization, exact 74-byte .mii, XML, PNG/JPEG, repair/cancel, query sharing and persistence across container restart. No native Intel/AMD physical host or Windows Docker host certification is claimed. The Docker image uses the same editor code, with no codec/renderer/artwork change or increased Wii compatibility guarantee.
