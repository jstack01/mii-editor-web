## Mii Editor Web v0.1.0-preview.3 — prerelease

Adds locally bundled **Load: Default Boy | Default Girl** links beneath the original-style editor. They use the historical records linked by https://mii-editor.nekoweb.org/, preserve their appearance and allocate fresh IDs with unknown ownership through the existing software policy. No runtime request to the historical site is needed.

Local launchers now read **config.json** beside the script: {"port":8080}. To change the local server port, open config.json in a text editor, change the number next to port, save the file, and restart Mii Editor. The server still binds only to 127.0.0.1, rejects invalid configuration, waits for readiness and opens the browser. Export important .mii files first: changing the port changes browser storage origin. Existing Python 3.9+ is required; nothing installs automatically. Static hosting needs neither config.json nor Python.

Fixes the mobile page container’s unscaled layout overflow, excessive gap beneath the editor and interference with preset-link taps. Original 640×500 artwork and uniform scaling remain intact. Desktop/emulated mobile checks cover Chrome, bundled Chromium and WebKit; Firefox runtime startup was blocked by macOS helper/sandbox errors, installed Safari remote automation was disabled, and Edge/physical iOS/Android environments were unavailable. Known limitation: WebKit’s forced-offline automation mode refuses local file reads/image downloads; those existing tests still fail. Normal and HTTP-blocked file/image workflows pass. Native Safari offline behavior remains unverified. No real-device, native keyboard or physical Wii certification is claimed. The owner’s successful Windows/macOS tests apply to preview.2; preview.3 config logic uses the same shared Python implementation but has not been independently run on Windows/Linux.

Download the named macos, windows or linux ZIP for local use; choose the static ZIP for Apache/Nginx. Extract completely and read START-HERE.md.
