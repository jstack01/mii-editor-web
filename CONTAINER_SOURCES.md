# Container components and source information

The prepared v1.0.0 image uses Nginx Unprivileged **1.30.6 Alpine slim**, pinned to multi-platform index `sha256:e333a5b95605942b5e495645ee54fab02b112081de6dbe45d2ead3ef38e03e31`, upstream image source revision `679834d1aa245a42e680d380c6b57785cfaa2115`. It preserves non-root UID 101, internal port 8080 and the existing runtime restrictions. The slim variant removes unused optional image/GeoIP/JavaScript/XSLT modules; it does not alter the editor or add a service.

The exact runtime package/license inventory and upstream texts are in `LICENSES/container/` in source and `/usr/share/licenses/mii-editor-runtime/` in the image. The new runtime contains 21 packages from 14 origins rather than the preview image's 70 packages. All components retain their own terms, including GPL/LGPL/MPL obligations; neither the project MIT nor Nginx's license covers the whole image.
