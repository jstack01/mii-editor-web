# Original image-export interface — Phase 5B

Open File → Export. The original page now supports JPEG/PNG, size/zoom fields and vertical sliders, RGB background fields/sliders, Body/Background checkboxes, preview dragging and local Save. Back/Escape returns to Files; Done closes File. Settings persist while the application remains open and reset on reload, as original FileOptions instance properties do. No Mii binary data, share link or persistence value changes when editing image options or saving images. No network/PHP/image service is used.

## Recovered behavior

The image page is original sprite 352 frame 4. Twenty-five recovered dependencies expand the GUI catalog from 366 to 391 symbols. Original matrices, registrations, nesting, static glyph paths, RGB bars, PageArrow hover/press states, checkbox frames, text placement and dimming remain. Dynamic text uses the existing browser Arial substitute. Text-shadow metadata for oversizeTimes is retained; CSS text-shadow approximates that Flash drop-shadow filter and its 2-pixel blur, so exact glyph/filter rasterization is not certified.

Defaults are JPEG, size 50, zoom 25, background E3F3EF, Body on and Background on. JPEG disables/dims Background using the source half-RGB treatment. PNG permits background removal, showing a white preview backdrop while exporting alpha. The original JPGEncoder target is quality 90; browser canvas JPEG uses quality 0.9. Different encoders/quantization/chroma subsampling mean byte-identical JPEGs and identical compression artifacts are not claimed. PNG uses native lossless encoding.

Size is continuously bounded 10–800; zoom 0–100 with render scale `0.15 + zoom/100`. Vertical slider mouse Y clamps to -171..0, without a grab offset. RGB X clamps to -115.5..115.5; float positions are retained and channel bitwise composition truncates to integers, as source. Pointer capture handles outside release, cancel and teardown. Keyboard arrows, Home/End and Page Up/Down are browser accessibility extensions. Preview arrow keys pan; Shift steps ten pixels. No invented centering/reset control was added.

The bitmap preview is 250 × 250 locally; its recovered parent X scale is 1.0000762939453125, so original `exportPreview.width` is 250.01907348632812. Export scale is `(0.15+zoom/100)*sizeValue/exportPreview.width`; preview pan offsets are scaled by the same size ratio. Centers use BitmapUtils' original bounds formula. Body off hides the body but **does not recenter the head**: invisible body bounds still participate, confirmed in unmodified Ruffle. The existing complete SVG scene remains the only character renderer.

Displayed size/zoom round while internal slider values stay fractional. BitmapData dimensions truncate positive sizeValue to integers, while its scaling formula still uses the unrounded value; this difference is preserved. Numeric text commits on Enter/focus-out, updates both numeric fields, clamps values and restores NaN input. A subsequent focus-out can reapply rounded display text, as source. Background accepts up to six hex digits, including short hex. Paste filters before limiting length. An emptied background field initially leaves the old value intact; a format/background selection commits that empty text as black through source-style integer coercion. These are characterized legacy behaviors, not future Wii-generation changes.

## Rasterization and resource handling

Export builds an independent character scene and a self-contained SVG with original vectors, masks, color transforms, multiply layers and blur. It rasterizes through a local Blob URL into Canvas, composites an opaque RGB background unless transparent PNG, then encodes to Blob and requests a browser download. Filenames reuse the existing Unicode/sanitization policy. No editor GUI pixels, diagnostics overlays or warning PNG backgrounds are exported.

Save snapshots the current 74-byte model and image settings. Later option changes cannot alter that pending export. Leaving the page cancels late downloads; failures report an error and preserve all data. SVG/download URLs are revoked and temporary canvas storage released. Repeated exports and offline operation are tested. Preview SVG versus original bitmap antialiasing and the existing source-shadow/Ruffle blur discrepancy remain documented visual limits. The source 25×15 body box blur is retained; it was not reshaped to fit Ruffle.

## Verification and baseline gate

272 unit tests, all previous XML/rendering/editor/file/storage/compatibility browser suites plus new image tests in development and production, TypeScript/build and seven Python recovery/integrity tests pass. Image checks decode real JPEG/PNG downloads and verify 10/50/800 sizes, alpha/background pixels, body visibility, camera/pan, fractional size, text/coercion, every slider family, native/scaled pointer capture/outside release/cancel, keyboard, navigation, snapshot/cancellation, Unicode filenames, repeated offline saves and URL cleanup. Firefox/WebKit executables remain unavailable; no cross-engine or physical-device certification is implied. Existing build chunk warning remains.

Matching default/head/transparent pages were captured from unmodified original SWFs in Ruffle 0.7.1 wgpu-webgl at native and 2× density. The original offline connectivity alert was dismissed using its UI; no network service was stubbed and no actual original image download was obtained. References therefore validate preview/layout/geometry, not original JPEG bytes. Galleries use exact source coordinates with no fitted alignment or parity threshold. No Adobe Flash pixel-perfect claim is made.

Integrity compares every application source/asset and the exact content file set: 1,718 files remain unchanged. Four of seven Git-ignored .DS_Store files changed during the session; none was modified/restored by this implementation. Before/after hashes are retained, and the guard now excludes only exact .DS_Store basenames with a regression test, leaving every source/asset protected.

This completes the approved functional reproduction scope, with incomplete tutorial and known visual/browser verification limitations still disclosed. Commit this baseline before Phase 6.
